# 一起看 P2P · Watch Together

> 异地情侣 / 朋友远程一起刷抖音、看 B 站、追剧的浏览器插件。**端到端 WebRTC 直连**，不需要自建服务器，边看边聊（文字 + 语音），聊天还能变成弹幕。

![icon](icons/128.png)

## 功能

- 🔗 **P2P 直连**：基于 WebRTC DataChannel（PeerJS），同步指令和聊天内容点对点传输，不经过任何自建服务器
- ⏯ **播放同步**：播放 / 暂停 / 拖动进度 / 倍速，任意一方操作，所有人跟着变；房主每 3 秒校准一次，偏差 > 2 秒自动对齐
- 📱 **跟着刷**：一方切换视频（抖音上下滑、B 站换集、YouTube 换视频），另一方自动跳到同一个视频
- 💬 **边看边聊**：页面右下角浮动聊天面板（可拖动、可收起），全屏时也能用
- 🌊 **弹幕**：聊天消息从视频上飘过
- 🎙 **语音通话**：一键开麦，声音 P2P 直连（成员两两直连）；对方开麦你直接就能听到，自己开麦才会说话；支持静音
- 👥 **多人房间**：房主转发，支持 2 人以上
- 🔁 **页面跳转不断线**：连接保存在 offscreen 文档里，页面刷新 / 跳转都不会掉线

### 已适配站点

| 站点 | 视频识别 | 跟随切换 |
| --- | --- | --- |
| 抖音 douyin.com | 推荐流当前视频 / `/video/<id>` / `modal_id` | ✅ 一方刷，另一方跟到同一条视频 |
| B 站 bilibili.com | `BV` 号 + 分 P、番剧 `ep/ss` | ✅ |
| YouTube | `watch?v=` / Shorts | ✅ |
| 其他任意网站 | 自动找页面上最大的 `<video>` | 按 URL 跟随 |

## 安装

1. 下载本仓库（`Code → Download ZIP` 解压，或 `git clone`）
2. Chrome / Edge 打开 `chrome://extensions`，打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目文件夹
4. 两个人都要安装（需 Chrome 116+ / Edge 116+）

## 使用

1. A 打开要看的视频页 → 点插件图标 → **创建房间**，把 6 位房间码发给 B
2. B 打开视频网站 → 点插件图标 → 输入房间码 → **加入**
3. 页面右下角出现聊天面板，绿点表示已连接，开始一起看 🎉
   - 播放 / 暂停 / 拖进度会自动同步
   - A 刷到下一个视频，B 会自动跟上（面板里可关闭「跟随切换视频」）
   - 进度不一致时点 **⇆ 让大家同步到我**
4. 想说话：点面板上的 **🎙 语音**（或插件弹窗里的「开启语音」）
   - 第一次会弹出一个页面申请麦克风权限，点允许即可（只需一次）
   - **建议戴耳机**，否则视频声音会被麦克风收进去，对方会听到回声
   - 对方开麦后你会自动听到（面板显示「🔊 某某（你只在听）」），点 🎙 语音 后双方互通

> 浏览器会拦截没有用户交互的自动播放，第一次同步时如提示，在视频上点一下即可。

## 原理

```
┌──────── 你的浏览器 ────────┐                 ┌──────── 朋友的浏览器 ───────┐
│ content.js  (视频/聊天UI)  │                 │  content.js                │
│      ⇅ chrome.runtime     │                 │      ⇅                     │
│ background.js (状态/路由)  │                 │  background.js             │
│      ⇅                    │   WebRTC P2P    │      ⇅                     │
│ offscreen.js (PeerJS) ◀────┼─────────────────┼────▶ offscreen.js          │
└────────────────────────────┘        ▲        └────────────────────────────┘
                                      │ 仅握手（交换 SDP）
                              PeerJS 公共信令服务器
```

- **offscreen 文档**持有 WebRTC 连接，因此标签页跳转、刷新不会断线
- **房间码**即房主的 Peer ID（`wtp2p-XXXXXX`），成员通过 PeerJS 公共信令服务器找到房主后建立直连
- 只同步「播放指令」，每个人用自己的账号在自己的网站上播放，**不传输视频画面**，清晰度不打折、也不消耗对方上行带宽
- 消息协议：`state`（播放状态）、`nav`（切换视频）、`chat`（聊天）、`members`（成员列表）、`voice`（语音开关）
- 语音走 WebRTC 媒体通道（Opus 编码，自带回声消除/降噪），成员之间网状直连；offscreen 页面无法弹出授权框，所以首次使用时打开 `permission.html` 让扩展获得麦克风权限

### 已知限制

- 双方都处于对称型 NAT 时，可能需要 TURN 中继（PeerJS 默认配置包含公共 TURN，但稳定性不保证）
- 抖音 / B 站的页面结构可能变化，视频识别失效时欢迎提 Issue / PR
- 会员内容需双方都有对应会员

## 开发

纯原生 JS，无构建步骤。改完代码在 `chrome://extensions` 点刷新即可。

```
manifest.json     MV3 清单
background.js     Service Worker：状态、消息路由、标签页绑定
offscreen.js      P2P 连接（PeerJS），房主星型转发 + 语音网状直连
content.js        视频识别、同步逻辑、聊天面板、弹幕
popup.*           创建 / 加入房间、语音开关
permission.*      首次使用语音时申请麦克风权限
lib/peerjs.min.js PeerJS 1.5.4（MIT）
```
